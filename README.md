# همراهان امید — نمونه‌کار وب‌سایت خیریه (فارسی / RTL)

یک نمونه‌کار کامل و قابل ارائه از یک وب‌سایت سازمان مردم‌نهاد: طراحی فارسی و راست‌چین، پنل مدیریت
متصل به پایگاه داده، فرم‌های واقعی، جریان کمک مالی شبیه‌سازی‌شده و زیرساخت سئو/امنیت.

> **این سایت نمایشی است.** «همراهان امید» یک مؤسسه فعال نیست. تمام پروژه‌ها، اخبار، گزارش‌ها و
> اعداد، داده نمونه هستند و در رابط کاربری با برچسب «داده نمونه» مشخص شده‌اند. هیچ پرداخت واقعی
> انجام نمی‌شود و هیچ شماره ثبت، مجوز یا آمار واقعی در پروژه وجود ندارد.

---

## ۱. نمای کلی

| بخش | فناوری | مسیر |
| --- | --- | --- |
| وب‌سایت و پنل مدیریت | React 18 + Vite + Tailwind CSS (RTL) | `src/` |
| API | Node.js 22 + Express 4 | `server/src/` |
| پایگاه داده | PostgreSQL 16 | `server/src/schema.sql` |
| فایل‌های بارگذاری‌شده | دیسک سرور (حجم Docker) | `uploads/` |
| محیط اجرا | Docker Compose | `docker-compose.base44.yml` |

**صفحات عمومی:** صفحه اصلی، درباره بنیاد، مأموریت، حوزه‌های فعالیت (+جزئیات)، پروژه‌های حمایتی
(+جزئیات)، اخبار و مقالات (+جزئیات)، گزارش‌های فعالیت و شفافیت، فرم داوطلبی، تماس با ما، حمایت مالی
(سه مرحله)، سیاست حفظ حریم خصوصی، شرایط استفاده، صفحه‌های دلخواه ساخته‌شده در پنل و صفحه ۴۰۴.

**پنل مدیریت (`/admin`):** داشبورد، پروژه‌ها، اخبار و مقالات، حوزه‌های فعالیت، صفحه‌ها، گزارش‌های
فعالیت، رسانه و فایل‌ها، کمک‌های ثبت‌شده، درخواست‌های داوطلبی، پیام‌ها و خبرنامه، کاربران و سطح
دسترسی، گزارش فعالیت مدیران، تنظیمات سایت و پشتیبان‌گیری.

## ۲. اجرا در محیط توسعه

```bash
docker compose -f docker-compose.base44.yml up -d --build
docker compose -f docker-compose.base44.yml ps
```

- وب‌سایت: <http://localhost:3000>
- API (از طریق پروکسی): <http://localhost:3000/api>  ·  مستقیم: <http://localhost:8000/api>
- سلامت سرویس: `curl -s localhost:3000/api/health`
- نقشه سایت: <http://localhost:3000/sitemap.xml> · <http://localhost:3000/robots.txt>

نصب وابستگی‌ها هنگام بالا آمدن کانتینر انجام می‌شود (`npm install` روی حجم‌های `node_modules`)،
بنابراین تغییر `package.json` فقط به restart سرویس نیاز دارد، نه بازسازی ایمیج.

### حساب نمایشی پنل

```
admin@hamrahanomid.ir     /     Hamrahan1404!
```

این مقادیر پیش‌فرض توسعه در `.env.base44-defaults` هستند و مقادیر واقعی داشبورد Secrets
(`/run/base44/app.env`) آن‌ها را بازنویسی می‌کنند. **در هر استقرار واقعی، رمز را از
«تنظیمات سایت → تغییر رمز عبور» عوض کنید.**

## ۳. منطق داده و صداقت نمایشی

- **داده نمونه مشخص است:** رکوردهای اولیه (پروژه‌ها، مقالات، گزارش‌ها) ستون `is_sample` دارند و در
  سایت با برچسب «داده نمونه» نمایش داده می‌شوند.
- **پرداخت شبیه‌سازی‌شده:** در نبود درگاه واقعی، کاربر مسیر «انتخاب مبلغ → اطلاعات اهداکننده →
  صفحه تأیید → نتیجه» را طی می‌کند. رکورد با `simulated = true` ثبت می‌شود، برچسب
  «پرداخت شبیه‌سازی‌شده» می‌گیرد و **در آمار کمک‌های واقعی محاسبه نمی‌شود**. هیچ داده کارت بانکی
  درخواست یا ذخیره نمی‌شود.
- **آمار بدون ساختگی:** اعداد صفحه شفافیت از پایگاه داده خوانده می‌شوند. اگر مقداری ثبت نشده باشد،
  «اطلاعات در حال به‌روزرسانی است» نمایش داده می‌شود، نه یک عدد نمونه.
- **پیام نمونه‌کار:** در بالای همه صفحات و در فوتر نوشته می‌شود که این سایت نمایشی است؛ از
  «تنظیمات سایت → حالت نمونه‌کار» قابل خاموش‌کردن است.

## ۴. امنیت

- نشست مدیر با کوکی `httpOnly` و JWT امضاشده (`JWT_SECRET`).
- کنترل دسترسی سمت سرور با سه نقش: `admin` (کامل)، `editor` (محتوا و رسانه)، `viewer` (فقط مشاهده).
- محدودیت تلاش ورود: ۸ تلاش ناموفق در ۱۰ دقیقه به ازای هر IP + ایمیل.
- محدودیت نرخ روی فرم‌های عمومی (تماس، داوطلبی، خبرنامه، کمک مالی).
- اعتبارسنجی و پاک‌سازی همه ورودی‌ها در سرور؛ اعداد فارسی/عربی به لاتین نرمال می‌شوند.
- مسدودسازی نوع فایل بارگذاری (SVG رد می‌شود)، سقف ۸ مگابایت، نام فایل تولیدشده در سرور.
- هدرهای امنیتی پایه، غیرفعال‌بودن `x-powered-by`، و پیام خطای عمومی بدون افشای جزئیات.
- ثبت رویدادها: ورود، خروج، تلاش ناموفق، ایجاد/ویرایش/حذف و تغییر کاربران در «گزارش فعالیت مدیران».
- پشتیبان‌گیری: خروجی JSON از داشبورد + دستور `pg_dump` در مستندات.

جزئیات بیشتر: [`docs/SECURITY.md`](docs/SECURITY.md)

## ۵. سئو و کیفیت

- عنوان، توضیح متا، canonical، Open Graph و Twitter Card اختصاصی هر صفحه (`src/lib/seo.jsx`).
- داده ساختاریافته JSON-LD: سازمان، مقاله و مسیر راهنما (Breadcrumb).
- `sitemap.xml` پویا از پایگاه داده و `robots.txt` با مسیرهای خصوصی مسدودشده.
- نشانی‌های خوانا (`/projects/:slug`، `/stories/:slug`، `/p/:slug`) با slug یکتا در سرور.
- متن جایگزین تصاویر، ساختار عنوان‌های منطقی، پرش به محتوا، فوکوس قابل مشاهده، پشتیبانی از
  `prefers-reduced-motion` و کنتراست رنگ‌های سیستم طراحی.
- تصاویر با `loading="lazy"`، فونت خودمیزبان (بدون درخواست به دامنه سوم).


## ۸. وابستگی به Base44

کد اپلیکیشن به Base44 وابسته نیست: نه SDK، نه دیتابیس مدیریت‌شده و نه سرویس اختصاصی. تنها
وابستگی‌ها در **لایه محیط** هستند:

1. `docker-compose.base44.yml` برای اجرای محیط توسعه.
2. متغیرهای محیطی پلتفرم (`BASE44_PREVIEW_MODE`، `BASE44_PUBLIC_HOST_SUFFIX`،
   `BASE44_SANDBOX_HOST_DOMAIN`) و فایل `/run/base44/app.env` برای Secrets.
3. یک بازنویسی کوچک در `vite.config.js` که فقط وقتی `BASE44_PREVIEW_MODE === "1"` است، دامنه
   sandbox را به allowlist اضافه می‌کند.

راهنمای حذف این وابستگی‌ها: [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md).
