# YAS SPORTS | یاس اسپورت

فروشگاه اینترنتی کفش و پوشاک ورزشی — فارسی، راست‌چین و کاملاً واکنش‌گرا.

## اجرا

```bash
docker compose -f docker-compose.base44.yml up -d --build
```

- فروشگاه: http://localhost:3000
- API: http://localhost:3000/api (پروکسی‌شده از سمت Vite)
- پنل مدیریت: http://localhost:3000/admin

حساب مدیر پیش‌فرض (توسعه): `admin@yas-sports.ir` / `yasadmin1405`

## ساختار

| مسیر | توضیح |
| --- | --- |
| `web/` | اپلیکیشن React + Vite (فارسی، RTL) |
| `api/` | API با Express و PostgreSQL (احراز هویت با کوکی JWT) |
| `web/public/images/` | تصاویر محصولات و بنرها |
| `web/src/styles/` | سیستم طراحی (توکن‌ها، تایپوگرافی، کامپوننت‌ها) |

## امکانات

- صفحه اصلی: هیرو سینمایی، کالکشن، بنر شهری، مزایای خرید، خبرنامه
- فروشگاه با فیلتر دسته‌بندی، جنسیت، قیمت، سایز، رنگ، مرتب‌سازی و جست‌وجو
- صفحه محصول با انتخاب سایز/رنگ/تعداد، موجودی و محصولات مرتبط
- سبد خرید (ذخیره‌شده در مرورگر) و کشوی سبد خرید
- ثبت سفارش با اعتبارسنجی فرم و کاهش موجودی در سمت سرور
- حساب کاربری، تاریخچه سفارش‌ها، خبرنامه و فرم تماس
- پنل مدیریت: محصولات (افزودن/ویرایش/حذف/آپلود تصویر)، سفارش‌ها، دسته‌بندی‌ها، مشتریان
- صفحات اطلاعاتی (راهنمای خرید، ارسال، بازگشت کالا، سایزبندی، سوالات متداول، قوانین و…)

## نکته پرداخت

درگاه پرداخت آنلاین به فروشگاه متصل نیست. سفارش ثبت می‌شود و وضعیت آن «در انتظار بررسی»
است؛ هیچ پرداختی در این مرحله انجام نمی‌شود.
