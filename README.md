# همراهان امید — وب‌سایت خیریه حمایت از زنان و کودکان بلوچ

وب‌سایت رسمی مجموعه «همراهان امید» به زبان فارسی و راست‌چین (RTL)، با پنل مدیریت برای تغییر تمام
محتواها بدون نیاز به کدنویسی.

## ساختار پروژه

| بخش | مسیر | توضیح |
| --- | --- | --- |
| وب‌سایت (React + Vite + Tailwind) | `src/` | همه صفحات عمومی و پنل مدیریت |
| API (Node.js + Express) | `server/src/` | احراز هویت، محتوا، فرم‌ها، درگاه پرداخت |
| پایگاه داده | PostgreSQL | جدول‌ها در `server/src/schema.sql` |
| فایل‌های بارگذاری‌شده | حجم `uploads` | تصاویر و PDF گزارش‌ها |

## اجرا در محیط توسعه

```bash
docker compose -f docker-compose.base44.yml up -d --build
```

- وب‌سایت: <http://localhost:3000>
- API: <http://localhost:3000/api> (از طریق پروکسی Vite) یا <http://localhost:8000/api>
- پنل مدیریت: `/admin`

سرویس `api` در هر بار بالا آمدن، شمای پایگاه داده را (به‌صورت idempotent) می‌سازد و داده‌های
اولیه را فقط در صورت خالی بودن جداول ثبت می‌کند.

## پنل مدیریت

دسترسی با ایمیل و رمز عبور تعریف‌شده در متغیرهای محیطی:

```
ADMIN_EMAIL=admin@hamrahanomid.ir
ADMIN_PASSWORD=Hamrahan1404!
```

این مقادیر «پیش‌فرض توسعه» هستند (`.env.base44-defaults`) و با مقادیر واقعی داشبورد Secrets
بازنویسی می‌شوند. **پس از نخستین ورود، رمز عبور را از «تنظیمات سایت → تغییر رمز عبور» عوض کنید.**

امکانات پنل: مدیریت پروژه‌ها، داستان‌ها و اخبار، حوزه‌های فعالیت، گزارش‌های مالی (با بارگذاری PDF)،
مشاهده کمک‌های ثبت‌شده، درخواست‌های داوطلبی، پیام‌های تماس، اعضای خبرنامه و تنظیمات کامل سایت
(نام مجموعه، متن‌های صفحه اصلی، اطلاعات تماس، شبکه‌های اجتماعی، تصاویر و آمار مستند).

## درگاه پرداخت

پرداخت آنلاین به‌صورت پیش‌فرض **غیرفعال** است، چون اطلاعات درگاه در اختیار پروژه نیست. در این حالت
فرم حمایت مالی، درخواست را با «کد پیگیری» ثبت می‌کند و همکاران مجموعه برای هماهنگی پرداخت تماس
می‌گیرند؛ هیچ تراکنشی «موفق» علامت نمی‌خورد.

برای اتصال درگاه زرین‌پال این مقادیر را در Secrets تنظیم کنید:

```
PAYMENT_GATEWAY=zarinpal
PAYMENT_MERCHANT_ID=<merchant id>
PUBLIC_BASE_URL=https://<نشانی-عمومی-سایت>
```

پس از آن، کاربر به صفحه بانک منتقل می‌شود و تنها پس از تأیید وریفای زرین‌پال، تراکنش در پایگاه داده
`paid` می‌شود. درگاه دیگری را می‌توان با افزودن آداپتور در `server/src/payments.js` اضافه کرد.

## اصول محتوایی و حریم خصوصی

- تصاویر و متن‌ها از پنل مدیریت بارگذاری می‌شوند؛ تا زمانی که تصویر واقعی ثبت نشود، طرح نمادین
  (غیرتصویری) نمایش داده می‌شود تا از تصویرسازی یا استفاده از عکس بدون مجوز پرهیز شود.
- آمار مالی فقط از تراکنش‌های تأییدشده محاسبه می‌شود؛ اعداد ثبت‌نشده با «اطلاعات در حال به‌روزرسانی
  است» نمایش داده می‌شوند.
- اطلاعات اهداکنندگان، داوطلبان و پیام‌ها در هیچ API عمومی برگردانده نمی‌شود.
